Enclave Breach

Controlled-channel attack · page-fault traces · data-oblivious code

Runs secret-dependent modular exponentiation inside a modelled enclave, shows the page-fault trace an untrusted operating system sees, rebuilds the secret exponent from that trace alone, and rewrites the code so every exponent leaves the same trace.

WHY IT MATTERS

A trusted enclave hides memory contents from the operating system, but not which pages it touches. When code takes secret-dependent branches, the OS can read the secret from the order of page faults — with no bug in the encryption at all.
